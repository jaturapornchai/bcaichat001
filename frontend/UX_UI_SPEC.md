# UX/UI & API Specification — BC Ai Chat (`d:\bcaichat\frontend`)

## 1. แนวคิดหลัก: 100% Personal + Mobile-First + Minimal Popups
1. **แชทส่วนตัว ครอบครัว และแก๊งเพื่อน (ธีมดินเผาบ้านเชียง `ban_chiang`)**:
   - ออกแบบบนโทนดินเผาบ้านเชียง (`#812920`, Deep `#681F18`, Soft `#FFDAD5`, Bubble `#FADBD4`, Mist Ivory `#FBF9F8`, Terracotta Night `#1C1412`, Ban Chiang Cream `#F5EFEA`) พร้อม 7 ธีมสีไทยร่วมสมัยที่สลับและซิงค์สดข้ามทุกเครื่อง
   - **กฎเหล็ก UI (Baseline-First)**: ข้อความ ปุ่ม ช่องกรอก ไอคอน และ Badge ในแถวเดียวกันต้องอยู่ระนาบ Baseline และกึ่งกลางแนวนอนเดียวกัน (`crossAxisAlignment: CrossAxisAlignment.center`) ห้ามเหลื่อมสูง-ต่ำ
   - **Mobile-First & Minimal Popups**: เปิดแอปแล้วเข้าหน้า **แชท (index 1)** ทันทีเหมือนแอปแชทมือถือจริง และใช้แผงยืดหดในหน้า (Inline Panels / Trays) แทนการเปิด `showDialog` / `showModalBottomSheet` ซ้อนทับหน้าจอ
   - รองรับ Native 4 แพลตฟอร์ม (`android`, `ios`, `windows`, `macos`) — ห้ามสร้างโฟลเดอร์ `frontend/web/`

2. **โครงสร้าง 4 แท็บหลัก & ฟีเจอร์ในห้องแชท**:
   - **Production Auth & กู้คืนบัญชี (ไม่มี Demo Login)**:
     - เข้าสู่ระบบด้วย **เบอร์โทร OTP (SMSMKT)** พร้อมรหัสอ้างอิง `Ref Code` และคูลดาวน์ 60 วินาที, **Verified Google OAuth2** (`url_launcher` + poll), และ **Owner Bootstrap Admin** (เปิดเฉพาะตอนยังไม่มีแอดมินคนแรก)
     - กู้คืนบัญชีเปลี่ยนเบอร์โทรหรือเปลี่ยน Gmail ด้วยตนเอง (PIN 6 หลัก + รหัสสำรองใช้ครั้งเดียว `BCRC-XXXX-XXXX` 6 ชุด) พร้อมเพิกถอน JWT/WS เก่าแบบ O(1)
     - แก้ไข Server URL (`bcaichat_api_base` / `API_BASE_URL`) แบบ Inline ภายในหน้า Login
   - **แท็บ 0: หน้าหลัก (`หน้าหลัก`)**: โปรไฟล์ส่วนตัว, QR Code (`bcaichat://add/...` + Reset QR), เพิ่มเพื่อน 4 ช่องทาง (QR / เบอร์โทร / `@bc_id` / Email), ความเป็นส่วนตัว, สร้างกลุ่ม, เข้ากลุ่มด้วยรหัสเชิญแบบ Inline Collapsible Panels พร้อมจัดการรายการโปรด/ซ่อน/บล็อก/ลบเพื่อน และทางลัด **BCAiChatOA** + Mini-App ส่วนตัว
   - **แท็บ 1: แชท (`แชท` — ค่าเริ่มต้นเมื่อเปิดแอป)**:
     - ทางลัด **📌 Keep ส่วนตัว** ในส่วนหัวแชท + แถบโฟลเดอร์เลื่อนแนวนอนบนมือถือ: `ทั้งหมด`, `ส่วนตัว`, `ครอบครัว`, `กลุ่ม`, `ปักหมุด`, `ยังไม่อ่าน`, `เก็บถาวร` (ตัวกรอง `ครอบครัว` รองรับทั้ง `family` และ `work`)
     - **ภายในห้องแชท (`ChatRoomScreen`)**:
       - ปักหมุดประกาศหัวห้อง, ค้นหาข้อความในห้อง, โทรเสียง/วิดีโอผ่าน **LiveKit** (`call_inline_panel.dart`), สลับ 3 โทนพื้นหลัง (`ครีมบ้านเชียง`, `กลางคืนดินเผา`, `งาช้างอบอุ่น`)
       - โหมดข้อความ: `ปกติ` / `เรื่องด่วน` / `ส่งเงียบนอกเวลา` (`silent`), ตั้งเวลาลบข้อความอัตโนมัติ (`expire_at`), โหมดข้อความลับส่วนตัว (`🔒 ความลับส่วนตัว` ซ่อนบนหน้าจอก่อนแตะเปิดอ่าน), แท็ก `@all` / `@สมาชิก` / `@ai`
       - เมนู **`+`** Inline Tray: แชร์ตำแหน่งที่ตั้ง (`location` + OpenStreetMap Nominatim + แปลงลิงก์ Google Maps/พิกัด), ส่งนามบัตรแนะนำเพื่อน (`contact`), เกมสุ่มบันได (`ladder`), **BC Game Center (`เกมกลุ่ม AI` คลัง 100 เกมเดี่ยว/กลุ่ม + สุ่มเกม + 5 เอนจิน: `ควิซสายฟ้า AI`, `ใครคือสายลับ`, `ทายคำใบ้`, `โหวตฮา`, `ชาเลนจ์สร้างสรรค์ AI` + โฮสต์ BC AI ชวนเล่นอัตโนมัติพร้อมปุ่มเปิด/ปิดรายห้องและระยะเวลาเว้นช่วง)**, สติกเกอร์ชุด *"อารมณ์ดีดินเผาไทย"*, ข้อความเสียงปรับสปีด `1x / 1.5x / 2x`, การ์ดโต้ตอบ (`rich_card` และการ์ดชวนเล่นเกม `game_invite` พร้อมปุ่ม `🎮 เข้าร่วมเล่นเลย` / `🔕 ปิดชวนเล่นห้องนี้`), Rich Menu & คูปอง **BCAiChatOA**
       - กด `อ่านแล้ว X` ในกลุ่มเพื่อดูรายชื่อสมาชิกที่อ่านแล้วแบบ Inline, Emoji Reactions, ตอบกลับ, แก้ไขข้อความสด, ส่งต่อหลายห้อง, บันทึกเข้า Keep ส่วนตัว, ปิดเสียงห้องแบบตั้งเวลา, บล็อกแบบเงียบ, ลบเฉพาะฉัน, ยกเลิกทุกคน, ลบไร้ร่องรอย
       - เครื่องมือในห้องแบบ Inline Overlay / Composer Tray (ไร้ Dialog): **คลังรูปภาพ ไฟล์ถาวร & โน้ตห้อง**, **อัลบั้มรูป (`Albums`)**, **นัดเจอ & กิจกรรม (`Events / RSVP`)**, **โพลโหวต (`Polls`)**, **จัดการกลุ่ม & เชิญ 🤖 BC AI**, **BC AI สรุปแชทให้เข้าใจไว**, **AI เกลาคำพูด/คิดคำตอบ/แปลภาษา**, และ **AI อ่านภาพ & อ่านเอกสาร (PDF/Word/Excel/PowerPoint/Text)** แบบ Inline บนฟองภาพ/ไฟล์ทุกข้อความ (พิมพ์คำถามพร้อมแนบไฟล์ได้ทันที)
   - **แท็บ 2: สมุดบันทึก (`สมุดบันทึก`)**: สมุดบันทึกส่วนตัว (`สมุดบันทึก BC`) ซิงค์ข้ามเครื่อง ปักหมุด ถูกใจ คอมเมนต์ และสร้าง/แก้ไขโน้ตแบบ Inline
   - **แท็บ 3: ตั้งค่า (`ตั้งค่า`)**: ผูก/เปลี่ยนเบอร์โทร OTP & Gmail, ตั้งค่า PIN & รหัสสำรองกู้คืนบัญชี, ความเป็นส่วนตัว & รายชื่อที่บล็อก, เลือก 7 ธีมสีไทย, ตั้งค่าเสียง/DND และการแจ้งเตือนรายเครื่องแบบ Inline, จัดการ **BCAiChatOA** หลายร้าน & ทีมหลาย Role, และส่วนจัดการระบบเฉพาะแอดมิน (SMSMKT & Google Auth Settings, MinIO, ตั้งค่าผู้ช่วย BC AI แบบระบบจัดการอัตโนมัติ, Broadcast, สมาชิก)

## 2. Backend API Contract (`http://127.0.0.1:8096`)
- **Base URL**: `http://127.0.0.1:8096` (Android Emulator default: `http://10.0.2.2:8096`)
- **WebSocket URL**: `ws://127.0.0.1:8096/ws?token=<JWT>`
- **Header**: `Authorization: Bearer <JWT>`
- **Endpoints หลัก**:
  1. Auth, Linking & Recovery: `GET /api/auth/config`, `POST /api/auth/otp/request`, `POST /api/auth/otp/verify`, `POST /api/auth/google`, `GET /api/auth/google/start`, `GET /api/auth/google/poll`, `POST /api/auth/bootstrap-admin`, `GET /api/auth/me`, `PUT /api/auth/profile`, `POST /api/auth/link/phone`, `POST /api/auth/link/google`, `DELETE /api/auth/link/google`, `POST /api/auth/recovery/setup`, `GET /api/auth/recovery/logs`, `POST /api/auth/recover/change-phone`, `POST /api/auth/recover/change-google`
  2. Friends & Privacy: `GET /api/friends`, `PUT /api/friends/:id` (`is_favorite`, `is_blocked`, `is_hidden`), `DELETE /api/friends/:id`, `GET /api/users/search?q=&by=`, `POST /api/friends/add`, `PUT /api/users/me`, `POST /api/users/me/reset-qr`
  3. Conversations & Group: `GET /api/conversations?folder=all` (รองรับ `family` / `work`), `POST /api/conversations/keep`, `POST /api/conversations/direct`, `POST /api/conversations/group`, `POST /api/conversations/join`, `PUT /api/conversations/:id/meta`, `POST /api/conversations/:id/members`, `DELETE /api/conversations/:id/members/:member_id`, `PUT /api/conversations/:id/pin-message`
  4. Messages, Edit, Forward, Keep, Polls & Events: `GET /api/conversations/:id/messages`, `POST /api/conversations/:id/messages` (`text|sticker|image|file|audio|rich_card|poll|event|location|contact|ladder`), `PUT /api/messages/:id`, `POST /api/messages/:id/forward`, `POST /api/messages/:id/save-to-keep`, `POST /api/conversations/:id/read`, `POST /api/messages/:id/react`, `POST /api/messages/:id/delete-for-me`, `DELETE /api/messages/:id/unsend`, `POST /api/conversations/:id/polls`, `POST /api/polls/:id/vote`, `POST /api/polls/:id/close`, `POST /api/conversations/:id/events`, `GET /api/conversations/:id/events`, `POST /api/events/:id/rsvp`
  5. BCAiChatOA & LiveKit Calls: `POST /api/oa`, `GET /api/oa/mine`, `GET /api/oa/discover`, `GET /api/oa/:id`, `PUT /api/oa/:id`, `POST /api/oa/:id/follow`, `GET /api/oa/:id/members`, `POST /api/oa/:id/members`, `GET /api/oa/:id/coupons`, `POST /api/oa/:id/coupons`, `POST /api/oa/coupons/:id/claim`, `POST /api/oa/coupons/:id/redeem`, `POST /api/oa/:id/broadcast`, `POST /api/calls/start`, `GET /api/calls/active`, `POST /api/calls/:id/accept`, `POST /api/calls/:id/token`, `POST /api/calls/:id/decline`, `POST /api/calls/:id/hangup`
  6. Vault, Albums, Notes, AI, Games & Admin: `GET /api/conversations/:id/vault`, `GET /api/conversations/:id/albums`, `POST /api/conversations/:id/albums`, `POST /api/albums/:id/photos`, `DELETE /api/albums/:id`, `GET /api/notes?conversation_id=...`, `POST /api/notes`, `PUT /api/notes/:id`, `DELETE /api/notes/:id`, `POST /api/notes/:id/like`, `POST /api/notes/:id/comments`, `POST /api/ai/summarize`, `POST /api/ai/assist`, `POST /api/ai/analyze-message`, `GET /api/games/catalog`, `GET /api/conversations/:id/games/active`, `POST /api/conversations/:id/games`, `POST /api/conversations/:id/games/random`, `POST /api/conversations/:id/games/proactive-invite`, `GET /api/games/:id`, `POST /api/games/:id/join`, `POST /api/games/:id/start`, `POST /api/games/:id/answer`, `POST /api/games/:id/clue`, `POST /api/games/:id/vote`, `POST /api/games/:id/guess`, `POST /api/games/:id/submit`, `POST /api/games/:id/next`, `POST /api/games/:id/cancel`, `POST /api/upload`, `GET /api/mini-apps`, `GET /api/settings/theme`, `GET /api/admin/overview`, `GET /api/admin/users`, `PUT /api/admin/users/:id/role`, `PUT /api/admin/theme`, `GET/PUT /api/admin/auth-settings`, `GET/PUT /api/admin/ai-settings` (รวม `proactive_game_invites`), `POST /api/admin/ai-test`, `GET/POST/PUT/DELETE /api/admin/mini-apps`, `POST /api/admin/broadcast`
